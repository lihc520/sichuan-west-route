# 川西小环线国庆路书

面向 2026 年 9 月 30 日至 10 月 7 日、广州往返成都、5 人租车自驾的静态行程网站。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## GitHub Pages 发布

这是一个不需要构建步骤的静态网站。仓库推送到 GitHub 后，在仓库的 `Settings → Pages` 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

保存后等待 Pages 构建完成，即可通过 GitHub Pages 地址公开访问。

## 内容边界

- 路线、里程和预算用于出行决策，不代替实时导航、景区公告或交警指挥。
- 2026 年国庆专项交通管制截至 2026-08-17 尚未发布，出发前必须复核。
- 景区门票和开放时间以四姑娘山景区官网、阿坝旅游网最新公告为准。
- 24 个景点卡片均有本地图片，来源链接和许可说明位于对应卡片及页面底部。
